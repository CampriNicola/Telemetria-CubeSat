# Telemetria CubeSat

## Funzioni
Tramite sensori inseriti, è possibile controllare le soglie e gestire le allarmi in caso di superamento delle soglie

## Istruzioni di avvio
Inserire i dati dei relativi sensori e satelliti nel file main.py
Avviare il programma per simulare i risultati con i casi dei dati inseriti in precedenza
